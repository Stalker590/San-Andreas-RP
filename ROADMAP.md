# SAN ANDREAS RP — Master Engineering Roadmap (`ROADMAP.md`)

**Версия плана:** 1.0.0

**Целевая платформа:** open.mp Server v1.6.7+ (Linux x86/x64 Native)

**Язык реализации:** Pawn (`qawno` compiler, флаги `-O2 -d1`) + C++ SDK Components

**Язык интерфейса:** 100% Русский (кодировка `.pwn` и соединения БД — `Windows-1251 / CP1251`)

**База данных:** MySQL 8.0+ / MariaDB 10.11+ (`InnoDB`, `utf8mb4_unicode_ci`)

**Архитектурный паттерн:** Модульный монолит с событийно-ориентированной шиной (`y_hooks`), строгой инкапсуляцией (`static stock`), паттерном `Dirty-Flag` и моделью **Server-Authoritative**.

## Обзор архитектуры зависимостей и порядок сборки

      7. Освобождение мьютексов.

  * **Критерий готовности (DoD):** Рюкзак с вещами внутри динамически меняет свой вес в инвентаре игрока; переполнение багажника по массе или объему отклоняется сервером.
